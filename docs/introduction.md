# 简介 {#introduction}

Vue Animation Router 是一个基于 Vue.js 、Vue Router 和 Mitt 的动画路由库。它通过将丝滑的过渡动画封装到路由视图内，使得路由视图在切换
的时候更符合人的视觉习惯。它提供了一种非常简单的方式来创建带有动画的路由视图，正是因为这种简单的创建方式，从而使得它非常容易上手，
且对项目的侵入性非常小。只需要简单几步，你可以很方便的在 Vue.js 项目中去使用它，也可以很方便的去使用该动画路由库对你的旧项目进行升级
或改造。总而言之，开发该项目的目的就是为了让路由切换“动”起来。

## 项目起源 {#origin}

关于该项目的起源想法，来自于我们团队的一个校内项目实践。在校期间，我们 [TurboSnail 软件研发团队](https://github.com/turbosnailcn)
负责为学校开发一个校园生活平台，在我负责搭建和开发该平台的移动端Web应用的过程中，我产生了开发该项目（Vue Animation Router）的
想法。因为是面向用户的移动端Web应用，所以在用户体验和视觉上必然是非常讲究且要注重细节的，而当我在使用 Vue Router 进行项目路由
配置和开发的时候，我发现默认的 RouterView 在切换的时候，给我的感觉过于生硬，这在用户体验层面是非常不友好，视觉上是非常让人难受
的。虽然 Vue 官方提供了 Transition API 来解决 RouterView 切换时候的动画问题，但是这样每次使用 RouterView 或者开发其他新项目的
时候，都需要重新去编写 CSS 动画，这就造成了非常大的麻烦，且耗费了很多非必要的时间。于是我就想，能不能将常用的过渡动画与 RouterView
封装到一起做成一个组件，然后将这些带有过渡动画的 RouterView 组件打包成一个动画路由库，这样不仅使用起来方便很多，也能节省出用于重
复编写动画的这部分时间。所以，我萌生了开发该项目的想法。

## 为什么使用？ {#why-use}

正如上面所说，使用该动画路由库可以节省出用于重复编写动画的这部分时间。除此之外，它还提供了非常简单的方式来创建带有动画的路由视图，
以至于你初次上手它，也会觉得非常容易，对项目的侵入性非常小，且提供了非常多的配置参数来满足你的定制需求。总而言之，如果你需要为你
的 Vue 项目添加一些带有过渡动画的路由视图，那么该 Vue Animation Router 对你来说是或许是一个不错的选择。

## 为什么叫这个名称？ {#why-name}

之所以叫这个名字，是因为它的核心就是将 Vue Router 的默认的 RouterView 组件封装成带有动画的组件。所以，它的着重点在于 Animation
（动画）的封装，其次才是Router（路由）的使用，所以它叫 Vue Animation Router 。（才不是因为“ Vue Router Animation ”这个名称，在
GitHub上已经被占用了的原因，才不是呢！😎）
